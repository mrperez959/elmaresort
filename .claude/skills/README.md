# Agent skills

Design-engineering skills by Emil Kowalski (https://github.com/emilkowalski/skills, MIT license,
see LICENSE-emilkowalski-skills). Claude Code picks them up automatically when working in this repo.

Useful ones for this site:
- `emil-design-eng`: UI polish and animation principles.
- `review-animations` / `improve-animations`: audit the motion in the site.
- `animate`: build a new animation the right way.
- `mobile-native`: make the site feel native on phones.

To update: `npx skills@latest add emilkowalski/skills` or copy the folders again from the repo.
